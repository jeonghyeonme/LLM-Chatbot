# 📄 논문 초안: 인하공업전문대학 신입생을 위한 지능형 가이드 챗봇 '인덕이' 설계 및 구현

## [제목]
- **국문:** 마스코트 기반 인터페이스와 서버리스 아키텍처를 활용한 대학 신입생 지원 지능형 챗봇 설계 및 구현
- **영문:** Design and Implementation of an Intelligent Chatbot for University Freshmen using Mascot-Driven UI and Serverless Architecture

---

## [요약 / Abstract]
본 논문에서는 대학 생활에 생소한 신입생들이 학사 일정, 식단 정보, 강의실 위치 등 필수 학내 정보에 쉽고 친근하게 접근할 수 있도록 돕는 지능형 챗봇 플랫폼 '인덕이'를 제안한다. '인덕이'는 대학 마스코트를 활용한 사용자 친화적 UI를 제공하며, 운영 비용 최소화를 위해 Vercel Serverless Functions와 Supabase를 결합한 제로 코스트(Zero-Cost) 아키텍처를 채택하였다. 특히, 정기적인 데이터 크롤러를 통해 최신 학사 및 식단 정보를 유지하고, Gemini 1.5 Flash 모델을 활용하여 자연어 기반의 질의응답 기능을 구현하였다. 본 시스템을 통해 신입생들의 정보 접근 편의성을 높이고 대학 생활 적응을 효과적으로 지원할 수 있음을 확인하였다.

---

## I. 서론 (Introduction)
### 1. 연구 배경 및 필요성
매년 대학에 입학하는 신입생들은 방대한 학내 정보(학사 일정, 강의실 위치, 식단 등)를 파악하는 데 어려움을 겪는다. 기존 대학 홈페이지나 포털 시스템은 정보가 분산되어 있고, 모바일 환경에서의 접근성이 낮아 필요한 정보를 즉각적으로 얻기 어렵다. 최근 인공지능 기술의 발전으로 챗봇 서비스가 대중화되었으나, 대학 전용 챗봇은 높은 유지비용과 사용자 친화적이지 않은 인터페이스로 인해 지속적인 서비스 운영에 한계가 있다.

### 2. 본 연구의 목적
본 연구의 목적은 인하공업전문대학 컴퓨터정보공학과 신입생을 주 대상으로, 친근한 마스코트 UI를 통해 정보 접근 장벽을 낮추고 실시간 크롤링 데이터를 기반으로 정확한 정보를 제공하는 '제로 코스트' 챗봇 시스템을 구축하는 것이다.

---

## II. 시스템 설계 (System Design)
### 1. 서비스 아키텍처
본 시스템은 지속 가능한 운영을 위해 서버리스(Serverless) 기반의 전수 비용 제로 아키텍처를 지향한다.
- **Frontend:** React 19와 TypeScript를 사용하여 모바일 웹 앱(PWA) 형태로 개발. Tailwind CSS를 활용한 직관적인 UI 설계.
- **Backend:** FastAPI를 활용하여 경량화된 API 서버 구축 및 Vercel Serverless Functions를 통한 배포.
- **Database:** Supabase(PostgreSQL)를 사용하여 식단, 일정, 시설 정보를 저장하고, pgvector를 활용한 공지사항 벡터 검색 구현.
- **AI Logic:** Google의 Gemini 1.5 Flash 모델을 연동하여 자연어 처리 및 지능형 응답 생성.

### 2. 데이터 수집 및 처리 프로세스
- **자동 크롤링 시스템:** Python 기반의 맞춤형 크롤러를 설계하여 학사 일정(Schedule), 학생식당 메뉴(Meal), 학과 공지사항(Notice)을 주기적으로 수집.
- **데이터 정제 및 적재:** 수집된 데이터를 Pydantic 모델로 정제하여 Supabase DB에 자동 갱신(Increment Strategy).

---

## III. 시스템 구현 (Implementation)
### 1. 마스코트 기반 사용자 인터페이스 (Mascot-Driven UI)
- 학교 마스코트 '인덕이'를 메인 캐릭터로 설정하여 친근감 조성.
- 퀵 메뉴 버튼(식단, 일정, 지도, 공지)을 통해 검색 없이도 즉각적인 정보 제공.

### 2. 지능형 챗봇 기능
- Gemini API를 활용하여 "오늘 점심 메뉴 뭐야?", "4호관 205호 어디야?"와 같은 자연어 질의에 대해 데이터베이스와 연동된 정확한 정보 제공.
- RAG(Retrieval-Augmented Generation) 패턴을 적용하여 최신 공지사항 정보를 기반으로 답변 생성.

### 3. 주요 서비스 구현 화면
- **식단 및 일정 페이지:** 달력 형태와 리스트 뷰를 결합하여 시인성 확보.
- **캠퍼스 맵:** 강의실 위치 및 시설 정보를 직관적으로 확인할 수 있는 기능.

---

## IV. 결론 및 향후 과제 (Conclusions)
### 1. 연구 성과
본 연구를 통해 신입생들이 대학 생활에 필요한 필수 정보를 단일 플랫폼에서 통합적으로 소비할 수 있는 환경을 구축하였다. 특히 서버리스 아키텍처와 무료 티어 서비스들을 전략적으로 결합하여 상용 수준의 서비스를 운영 비용 없이 구축할 수 있음을 입증하였다.

### 2. 한계 및 향후 과제
현재는 컴퓨터정보공학과 위주의 정보를 제공하고 있으나, 향후 대학 전체 학과로 데이터 수집 범위를 확대하고 사용자 피드백을 기반으로 챗봇의 응답 정확도를 지속적으로 고도화할 계획이다.

# 📄 [학술 논문 초안] 서버리스 아키텍처와 RAG 기술을 활용한 대학 신입생 지원 지능형 가이드 플랫폼 설계 및 구현

## 국문 요약
본 논문에서는 대학 생활에 생소한 신입생들이 파편화된 학내 정보에 쉽고 친근하게 접근할 수 있도록 돕는 지능형 챗봇 플랫폼 '인덕이'를 설계하고 구현하였다. 제안하는 시스템은 대학 마스코트를 활용한 사용자 친화적 인터페이스를 제공하며, 지속 가능한 서비스 운영을 위해 Vercel Serverless Functions와 Supabase를 결합한 제로 코스트(Zero-Cost) 아키텍처를 채택하였다. 기술적으로는 Gemini 1.5 Flash 모델을 기반으로 한 LangChain 도구 설계와 SSE(Server-Sent Events) 스트리밍 기술을 적용하여 실시간 대화 경험을 극대화하였다. 특히, 텍스트 기반의 RAG(Retrieval-Augmented Generation)와 정적 데이터의 프론트엔드 직접 조회 하이브리드 전략을 통해 시스템 응답 속도를 최적화하였으며, 이를 통해 정보 제공의 정확성과 신속성을 확보하였다. 본 연구를 통해 구축된 시스템은 신입생의 정보 접근 편의성을 높이고 대학 생활 적응을 효과적으로 지원할 수 있음을 확인하였다.

---

## I. 서론
매년 대학에 입학하는 신입생들은 학사 일정, 강의실 위치, 학생식당 식단 등 필수적인 학내 정보를 파악하는 데 상당한 어려움을 겪는다. 기존 대학 홈페이지나 포털 시스템은 정보가 여러 게시판에 분산되어 있으며, 모바일 환경에서의 접근성이 낮아 필요한 정보를 즉각적으로 획득하기에 한계가 있다. 또한, 고도화된 인공지능 기술을 대학 전용 서비스에 도입하기에는 높은 클라우드 인프라 유지비용과 관리의 복잡성이 수반되는 실정이다. 이에 본 연구에서는 인하공업전문대학 신입생을 주 대상으로 하여, 친근한 마스코트 페르소나를 통해 심리적 정보 접근 장벽을 낮추고 서버리스 기술을 활용하여 운영 비용을 최소화한 지능형 챗봇 플랫폼 '인덕이'를 제안하고자 한다. 본 시스템은 실시간 데이터 크롤링과 최신 대형 언어 모델(LLM)을 결합하여 신입생들에게 정확하고 신속한 가이드를 제공하는 것을 목적으로 한다.

## II. 시스템 설계
본 시스템은 지속 가능한 운영과 높은 응답 성능을 동시에 달성하기 위해 제로 코스트 서버리스 아키텍처와 하이브리드 데이터 쿼리 전략을 채택하였다. 시스템의 프론트엔드는 React 19와 Vite를 기반으로 구축되어 Vercel에 배포되며, 백엔드는 FastAPI를 활용한 경량 API 서버가 Vercel Serverless Functions를 통해 트리거되는 구조를 가진다. 데이터베이스는 Supabase(PostgreSQL)를 사용하여 식단, 일정, 시설 정보를 저장하며, RLS(Row Level Security) 정책을 통해 보안을 강화하고 pgvector를 이용한 공지사항 벡터 검색 기능을 제공한다. 특히, 시스템의 성능 최적화를 위해 식단 및 시설 정보와 같은 정적 데이터는 프론트엔드에서 Supabase SDK를 사용하여 직접 조회함으로써 네트워크 지연 시간을 최소화하고, 챗봇 대화나 복잡한 지식 검색이 필요한 경우에만 백엔드 API를 경유하는 하이브리드 방식을 적용하였다.

## III. 시스템 구현
### 1. 지능형 챗봇 및 사용자 인터페이스
지능형 챗봇 '인덕이'는 대학 마스코트의 고유한 말투를 시스템 프롬프트에 반영하여 신입생들에게 친근한 브랜드 경험을 제공한다. LLM의 생성 지연 시간을 체감적으로 단축하기 위해 SSE(Server-Sent Events) 기술을 적용하였으며, 수신된 데이터를 20ms 간격의 `setInterval`을 이용한 타이핑 시뮬레이션 알고리즘으로 출력하여 인간과 대화하는 듯한 자연스러운 인터랙션을 구현하였다. 또한, `crypto.randomUUID()`로 생성된 세션 ID를 통해 2시간 동안의 대화 맥락을 유지함으로써 일관성 있는 답변이 가능하도록 설계하였다.

### 2. 효율적인 정보 분석 및 시각화
본 시스템은 대량의 학사 정보 및 공지사항을 효율적으로 전달하기 위해 텍스트 기반의 RAG(Retrieval-Augmented Generation) 파이프라인을 최적화하였다. 학사 일정의 경우, `useMemo`를 활용한 메모이제이션 기법으로 대량의 일정을 날짜별로 매핑하여 달력 렌더링 성능을 최적화하였다. 캠퍼스 가이드 기능은 `react-naver-maps`를 연동하여 주요 건물을 커스텀 마커로 표시하며, 사용자가 시설을 선택할 경우 `panTo()` 메서드를 호출하여 해당 위치로 부드럽게 화면을 이동시키는 동적 인터페이스를 제공한다.

### 3. 데이터 수집 자동화
정확한 정보 제공을 위해 Playwright를 활용한 동적 크롤러 서비스를 구축하였다. 이는 학교 홈페이지의 JavaScript 렌더링 콘텐츠를 완벽히 수집하며, 수집된 HTML 본문은 `html2text` 라이브러리를 통해 마크다운 형식으로 변환되어 저장된다. 이러한 데이터 정제 과정은 LLM의 토큰 소모를 줄이고 문맥 이해도를 높여 더 정교한 답변 생성을 가능하게 한다.

## IV. 결론 및 향후 과제
본 연구를 통해 고성능 LLM 서비스를 서버리스 아키텍처와 전략적으로 결합하여 운영 비용 부담 없이 상용 수준의 대학 지원 시스템을 구축할 수 있음을 확인하였다. 제안된 시스템은 타이핑 시뮬레이션과 하이브리드 쿼리 전략을 통해 사용자 경험과 시스템 성능을 동시에 확보하였으며, 마스코트 기반의 디자인은 신입생들의 학내 정보 접근성을 획기적으로 개선하는 성과를 거두었다. 향후 연구에서는 축적된 사용자 피드백을 기반으로 챗봇 답변의 정확도를 높이기 위한 파인튜닝(Fine-tuning)을 진행하고, 학과별 특화된 커리어 로드맵 데이터를 확충하여 전 학년을 아우르는 종합 지능형 학사 지원 시스템으로 고도화할 계획이다.
