# 인하덕(Inha-Duck): 대학 신입생을 위한 지능형 가이드 챗봇

## [발표 목차]
* **I. 프로젝트 개요:** 연구 배경, 목적 및 지향점
* **II. 시스템 아키텍처:** 제로 코스트 서버리스 스택 및 데이터 흐름
* **III. 주요 구현 기능:** 마스코트 인터페이스, RAG 검색, 동적 지도
* **IV. 성능 최적화:** 하이브리드 데이터 전략 및 자동화 파이프라인
* **V. 결론:** 기대 효과 및 향후 고도화 계획

## 1. 프로젝트 개요 및 목적
* **대학 생활의 첫 단추:** 파편화된 학내 정보(식단, 일정, 공지)를 한곳에서 제공
* **제로 코스트 지향:** Vercel과 Supabase를 활용한 **인프라 유지비 0원** 아키텍처
* **마스코트 기반 UI:** 대학 마스코트 '인덕이'를 활용한 친근한 인터랙션

## 2. 시스템 아키텍처
* **Frontend:** React 19, Tailwind CSS (Vercel 배포)
* **Backend:** FastAPI (Vercel Serverless Functions)
* **AI/DB:** Gemini 1.5 Flash + Supabase (pgvector)
* **특징:** 관리형 서비스(Managed Service) 중심의 효율적인 리소스 관리

## 3. 마스코트 기반 인터페이스 (UX)
* **선배의 말투:** 시스템 프롬프트 설계를 통한 친근한 대화 경험
* **SSE 스트리밍:** 실시간 토큰 전송으로 응답 지연 시간 체감 단축
* **타이핑 애니메이션:** 20ms 간격의 시뮬레이션으로 자연스러운 흐름 생성

## 4. 성능 최적화를 위한 하이브리드 전략
* **직접 조회(Direct):** 식단, 시설, 일정은 프론트엔드에서 DB 직접 쿼리 (초고속 응답)
* **AI 질의(LLM):** 복잡한 질문에만 서버리스 API 호출
* **효과:** 불필요한 백엔드 실행 최소화 및 인프라 소모 비용 절감

## 5. RAG 기반 지능형 공지사항 검색
* **벡터 검색:** Supabase pgvector를 활용한 공지사항 유사도 매칭
* **정확한 정보:** 실제 학사 공지 데이터를 기반으로 한 할루시네이션 방지
* **문서 정제:** HTML을 마크다운으로 변환하여 토큰 효율 200% 향상

## 6. 동적 캠퍼스 지도 가이드
* **네이버 지도 연동:** 실시간 위치 정보 시각화
* **인터랙션:** 챗봇 대화 내용에 따라 지도가 자동으로 해당 위치로 이동(panTo)
* **시설 정보:** 강의실, 식당, 편의시설 좌표 데이터 기반 커스텀 마커 표시

## 7. 자동화된 데이터 파이프라인
* **스마트 크롤러:** Playwright 기반의 동적 웹 수집 시스템
* **Pydantic 검증:** 수집된 데이터의 무결성 보장 및 자동 DB 갱신
* **최신성 유지:** 주기적인 크롤링을 통해 항상 최신 정보 제공

## 8. 결론 및 향후 전망
* **성과:** 제한된 자원(무료 티어)으로도 실용적인 고성능 챗봇 구현 가능성 입증
* **발전 방향:** 학과별 특화 데이터 확충 및 고도화된 답변 품질을 위한 파인튜닝
